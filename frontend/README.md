# Store Mini ERP (frontend)

React app for the store management system.

## Run in VS Code

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173/

Demo logins:

- owner@store.com / owner123
- manager@store.com / manager123
- cashier@store.com / cashier123
- stock@store.com / stock123

Data is stored in the browser until the Node/Express API is connected.
